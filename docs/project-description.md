# Project Description

## Overview

Git Practice Project is a small Python command-line calculator created for a Git and GitHub practical assignment. It demonstrates how to organize a project, make commits, work with branches, merge changes, and push a local repository to GitHub.

## Features

- Prints the author name and the current date.
- Adds, subtracts, and multiplies two numbers.
- Keeps calculator functions in `src/utils.py` and program output in `src/main.py`.

## Run

From the project folder, run:

```powershell
py src\main.py
```
